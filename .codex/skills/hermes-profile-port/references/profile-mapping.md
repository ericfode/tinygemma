# Profile Mapping

Recommended mapping from Hermes to Codex:

- `PROFILE.md` -> repo operating notes and scope boundaries
- `SOUL.md` -> persona or engineering-style guidance
- configured project root -> target repo root or repo-local docs
- attached skills path -> note in imported draft so Codex knows where to look

Suggested outputs:

- `docs/hermes-import/<profile-name>/PROFILE.md`
- `docs/hermes-import/<profile-name>/SOUL.md`
- `docs/hermes-import/<profile-name>/CODEX-AGENTS-DRAFT.md`

Only promote the draft into `AGENTS.md` if it fits the repo and the user wants that.
