# Bootstrap Layout

A minimal Codex repo harness baseline is:

- `AGENTS.md`
- `configs/repo-loop-state.json`
- `docs/plans/`
- `state/evolution-log.md`
- `state/procedure-candidates.json`

That is enough to support:

- resumable repo work
- explicit next-step tracking
- procedure extraction
- plugin installation into the repo marketplace
